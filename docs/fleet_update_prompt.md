# Maintenance task inputs

Give the maintenance agent an explicit host, program, intended full source
revision and the applicable private operator runbook. Include active holds and
running-job constraints. Do not put private inventory, accounts, credentials
or home paths into a public issue or source patch.

Require the agent to follow the [portable maintenance checks](fleet_update_runbook.md),
use the configured lane, record observed identities and preserve unknown
outcomes until verified. Updating the helper, the program runtime and the
private operations provider are separate changes with separate evidence.
